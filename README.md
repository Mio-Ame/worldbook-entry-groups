# 世界书条目分组 (Worldbook Entry Groups)

面向 SillyTavern 与 TauriTavern 的独立轻量世界书条目分组管理扩展。专门解决大型角色卡世界书条目繁多、多条 IF 分支混杂在同一列表中难以成组开关的问题。

## 功能特点

- **独立轻量面板，不改原生编辑器结构**：不包裹、不重排酒馆原生世界书条目编辑 DOM；读取时直连世界书数据并仅保留轻量条目摘要，关窗即释放内存，兼容移动端低内存环境。
- **零污染原世界书**：不修改条目标题，不占用酒馆原生包含组字段；所有分组归属按「世界书名称 + 条目 UID」保存在插件自身配置中。
- **三种分组模式**：
  - **普通组**：整组一键全开或全关，各组互不影响；
  - **IF 线互斥组**：开启某条 IF 线分组时，自动关闭本书其他标为「IF 线互斥」的分组；
  - **组内单选组**：开启组内任意一条时，自动关闭同组其余条目。
- **单次合并写盘**：整组开关或切换多条 IF 线时，所有条目状态变更合并为 1 次保存，并同步已加载的内存缓存与打开中的原生编辑器。
- **一键自动识别建组**：支持按标题前缀（如 `【世界观】`、`[IF1]`、`角色 - `）、分隔条区间（如 `=== 基础设定 ===`）及角色开场白注释标签（`<!-- lore: ... -->`）预览并生成分组，支持多步撤销。
- **开场白联动协调**：自动标记受角色首层开场白注释控制的条目，在切换开场白后错峰同步开关显示；支持从分组菜单一键复制 `<!-- lore: ... -->` 注释标签。
- **原生编辑器定位与跨扩展同步**：点击条目菜单可直接跳回酒馆原生世界书编辑器对应条目并高亮；自动响应 `wbo:worldbook-renamed` 与 `wbo:worldbook-deleted` 同步迁移或清理分组配置。

## 使用方式

1. 打开酒馆世界书面板，点击顶部工具栏中的层叠分组图标按钮（也可在聊天输入框执行 `/weg` 或 `/weg 世界书名称`）。
2. 点击右上角「自动识别」快速预览建组，或点击「新建分组」配合底部「多选移组」手动归类条目。
3. 需要多条剧情线二选一时，将对应分组设为「IF 线互斥组」，之后点一下该组总开关即可一键切线。
