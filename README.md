# 世界书条目分组 (Worldbook Entry Groups)

面向 SillyTavern 与 TauriTavern 的独立轻量世界书条目分组、存档阶段记忆与情境按需开关扩展。

## 功能特点

- **三处原生入口，随手可开**：
  1. 顶部「扩展」面板中的 **世界书条目分组** 折叠卡片；
  2. 聊天输入框左下角「魔法棒菜单」中的 **世界书条目分组**（聊到一半切阶段无需翻找世界书面板）；
  3. 世界书编辑面板顶部工具栏图标按钮；同时支持 `/weg` 与 `/weg 分组名` 斜杠命令。
- **零扫描存档锁线 & 单档跨阶段演进（多档不串线、大档不卡顿）**：
  - 仅在每个聊天存档头（`chatMetadata`）读写百字节级路线标记，**绝不扫描或遍历聊天记录正文**，几百 MB 长存档切档零负担；
  - 同一个存档从「18岁线」聊到中途穿越/推进到「30岁线」时，直接开启「30岁线」（或输入 `/weg 30岁线`），本存档阶段即刻更新为 30 岁线，后续刷新或切档回来绝不会退回旧开场白。
- **情境按需组（适配角色 NSFW / 特定场景条目）**：
  - 支持将亲密剧情（NSFW）等条目设为「情境按需组」：日常正剧时保持关闭（省 Token、防日常发情串戏）；
  - 发送消息生成前仅检测最新 1~2 条消息末尾短片段，命中情境词时在拼装世界书前当轮自动开启，剧情恢复日常几轮后自动关回。
- **独立固定尺寸面板 & 零污染原世界书**：
  - 不改条目标题，不占原生包含组字段；直读条目摘要、关窗即释放内存，批量切组只做 1 次写盘；
  - 支持一键自动识别（NSFW 条目 / 标题前缀 / 分隔条 / 开场白注释）、多步撤销、跳回原生编辑器定位，并响应 `wbo:worldbook-renamed` / `wbo:worldbook-deleted` 自动同步。
