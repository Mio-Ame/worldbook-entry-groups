# 世界书条目分组 (Worldbook Entry Groups)

面向 SillyTavern 与 TauriTavern 的独立轻量世界书条目分组与多存档切线管理扩展。专门解决大型角色卡世界书条目繁多、多条 IF 线（如 18 岁线 / 30 岁线）混在一起开关麻烦，以及开多个聊天存档聊了几层后切档无法自动认线的问题。

## 功能特点

- **按聊天存档独立认档切线（多档不串线）**：
  - 每个聊天存档通过自身 `chatMetadata`（外加本地配置双备份）独立记住所属的 IF 线分组与条目开关状态；
  - 即使聊了几十层、开了分支档（`/branch`）、首层注释被编辑掉，甚至中途插入了新时间线开场白，也能从楼层正文与角色卡全量开场白反推识别当前存档属于哪条线，并在切换存档（`CHAT_CHANGED`）时 1 次写盘自动切回对应世界书状态。
- **独立轻量面板，不改原生编辑器结构**：不包裹、不重排酒馆原生世界书条目编辑 DOM；读取时直连世界书数据并仅保留轻量条目摘要，关窗即释放内存，兼容移动端低内存环境。
- **零污染原世界书**：不修改条目标题，不占用酒馆原生包含组字段；分组归属按「世界书名称 + 条目 UID」保存在插件自身配置中。
- **三种分组模式**：
  - **普通组**：整组一键全开或全关，各组互不影响；
  - **IF 线互斥组**：开启某条 IF 线分组时，自动关闭本书其他标为「IF 线互斥」的分组，并自动锁入当前聊天存档；
  - **组内单选组**：开启组内任意一条时，自动关闭同组其余条目。
- **一键自动识别建组**：支持按标题前缀（如 `【世界观】`、`18岁线-`）、分隔条区间（如 `=== 基础设定 ===`）及角色开场白注释标签（`<!-- lore: ... -->`）预览建组，支持多步撤销。
- **原生编辑器定位与跨扩展同步**：点击条目菜单可直接跳回酒馆原生世界书编辑器对应条目并高亮；自动响应 `wbo:worldbook-renamed` 与 `wbo:worldbook-deleted` 同步迁移或清理配置。

## 使用方式

1. 打开酒馆世界书面板，点击顶部工具栏中的层叠分组图标按钮（也可在聊天输入框执行 `/weg` 或 `/weg 世界书名称`）。
2. 点击右上角「自动识别」快速预览建组，或点击「新建分组」配合底部「多选移组」将 18 岁线、30 岁线等设为「IF 线互斥组」。
3. 在任意聊天存档中开启对应 IF 线（或点状态栏「识别本档 / 锁定到本档」），之后来回切换不同聊天存档即可自动切换对应的世界书条目开关。
